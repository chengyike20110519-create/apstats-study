# AP 统计学刷题网站

## 怎么打开

**方式一（推荐，无需任何工具）**：直接双击 `index.html`，浏览器打开即可用。全部离线，题目、图片、知识点都打包在本地文件夹里。

**方式二（局域网/手机用）**：

```bash
cd site
python3 -m http.server 8734
# 浏览器访问 http://127.0.0.1:8734
```

## 功能

| 标签 | 内容 |
|---|---|
| 首页 | 总进度、正确率、错题数；按 21 个知识点小节进入刷题 |
| 选择题 | 练习册 500 道 MC，做完立刻显示对错 + 中文解析；做错的自动进错题本 |
| 简答题 | 100 道 FR，附参考答案（少数依赖原书图表的题无答案但有配图） |
| 错题本 | 自动收集错题，可一键重做；重做正确后自动移出 |
| 知识点 | 12 章中文知识点（整理自课件，含常错点提醒） |

**推荐学习动线**：知识点 → 学一章 → 点章内「学完就刷题」→ 立即刷对应小节的题 → 看战绩 → 「继续学下一章」。章节↔小节映射（12 章 ↔ 21 小节）写在 `js/app.js` 的 `CH_TOPICS`；章节会标记「✓ 已学」。

**多账号**：右上角 👤 菜单可新建/切换账号（可设 4 位 PIN），每个账号的做题记录、错题本、已学章节在本机完全独立。换设备时用「导出备份码」→ 新设备「导入备份码」迁移进度。注意：PIN 只是防误切，不是加密；进度默认只存本机浏览器。

**半期进度**：依据 2026-11-10 总复习课标注了班内讲到哪了（首页黄色卡片），首页可一键「刷班内已讲范围」(369 题)，知识点页有完整半期提纲。班内状态数据在 `js/app.js` 的 `TOPIC_CLASS` / `MIDTERM_OUTLINE`。

- 进度自动保存在浏览器 localStorage，换浏览器/清缓存会丢失（可先用备份码导出）。
- 已做对的题会排到该小节队尾，优先刷没做过的和做错的。

## 更新题库/答案

答案由 `batches/ans_mc_*.json` 与 `batches/ans_fr_*.json` 合并，改完后在 `apstats/` 目录跑：

```bash
python3 build_data.py
```
